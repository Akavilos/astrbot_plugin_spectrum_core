# 世界书使用指南

适用版本：光谱核心0.3.2。世界书用于保存世界观、人物背景、地点与规则等设定；在条目满足触发条件时加入当前上下文。

## 创建第一个条目

1. 插件配置 → 世界书与背景设定 → 打开“启用世界书”。
2. 打开光谱插件页面 → 世界书，新建并启用一条条目。
3. 填写标题、内容和主关键词。例如标题“旧书店”，关键词“书店”，内容填写店铺的位置、布局与背景。
4. 先使用默认“生活背景”位置。保存后在聊天中自然提到关键词，观察相关背景是否被使用。

稳定且始终需要的设定可选择常驻。普通条目使用关键词按需出现。关键词留空不会让条目自动常驻；此类条目走相关性检索，语义匹配还需要开启相应功能。

## 选择注入位置

四个位置都是光谱自行组织的上下文位置，**没有酒馆式的聊天消息深度注入**。触发词回看消息数只控制扫描哪些近期消息，与条目放在哪里无关。

| 页面位置 | 保存值 | 适用内容 |
|---|---|---|
| 合约与人设后 | `core` | 身世、稳定世界观、持续适用的背景规则 |
| 生活背景 | `l3` | 地点、环境、与当前生活相关的知识；默认位置 |
| 人物档案后 | `person` | 与人物有关的设定补充 |
| 当前阶段后 | `turn` | 当前阶段相关的背景说明 |

前台回复和后台推进使用相同的位置定义。位置靠后并不代表规则权限更高；人物档案后的条目也不会仅因位置就自动限制给某个人。世界书本身是全局设定源，是否出现取决于触发规则。

## 触发与筛选

- 主关键词：条目出现的基本条件；可设置大小写、全词匹配和正则匹配。
- 次关键词：主关键词命中后进一步筛选，可要求任一命中、全部命中、并非全部命中或全部不命中。
- 扫描深度：设置条目自己的回看消息数；0使用全局值。
- 概率：控制满足条件后的随机出现机会。
- 互斥组与优先级：安排同类条目之间的选择。
- 持续、冷却与延迟：控制条目在连续回合中的使用节奏。
- 递归：开启后允许一个条目的内容带出其他条目；全局轮数上限限制联动范围。
- 回合条件：持续、冷却和延迟按世界书使用回合计算，不是现实钟点的定时任务。

篇幅由全局条目数量上限、比例预算和绝对预算共同控制。命中条件并不保证条目一定进入上下文，预算和组内筛选也会影响结果。具体数值和0值含义见 [配置参考](配置参考.md)。

## 写法建议

一个条目写清一件事，避免把长期设定、临时事件和角色行动指令混在一起。角色自述材料用第一人称，例如“我在这座城长大，熟悉旧街区”；地点与外部世界可直接描述。

临时发生的外部场景使用 `/叙述事实`，已经发生的对话由往来记录和记忆保存。这样更容易判断一段内容是背景设定还是新事件。

面板按条目创建和编辑，没有世界书文件导入按钮。迁移其他平台的设定时，按条目复制标题、内容和关键词，并选择光谱的注入位置；外部文件中的聊天深度不能直接套用。先从少量条目开始，确认触发效果后再补充。
