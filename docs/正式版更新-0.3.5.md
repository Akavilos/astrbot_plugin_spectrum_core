# 光谱核心 0.3.5 正式版

本次更新针对插件市场指出的请求兼容问题，保留共同生活、人物关系、跨会话记忆、世界书、睡眠、主动联系、剧情导演和数据面板。数据库结构及数据目录不变，升级不清空聊天、人物、记忆或世界书。

## 请求与记忆

AstrBot 继续管理原生聊天历史、用户输入、图片、音频及工具调用。光谱在原系统提示末尾追加稳定的角色输出合约；时间、人物、记忆、世界书、棱镜心情和生活状态改用公开 `TextPart.mark_as_temp()` 接口提供，仅在本轮生效。前台、后台及格式重问均保留所需背景。

真实往来记录继续用于记忆、来源核验和后台生活，不再整体替换框架聊天历史。已有历史中的相同消息按次数去重，补充未收录的真实消息。世界书仍支持原有四个逻辑位置、触发规则、预算及回合条件；位置控制临时背景的段落顺序。

## 冻结与限流

保留持久化冻结、暂停时间补偿、冻结期间收信、解冻后恢复调度及拒绝跨冻结代次的旧结果。前台通过公开事件入口和发送前检查控制，后台通过自己的公开模型调用入口控制。

保留请求额度、排队超时及故障等待。限频范围为光谱前台请求入口和自己的后台调用。框架内部的工具续轮、HTTP 重试及其他插件独立请求由框架和各插件管理，不再通过全局供应商补丁拦截，也不改 SDK 重试参数。这是正式版与旧实验实现的范围差异。

## 角色思考与夺舍

普通角色思考记录仍可开关，不影响模型原生推理设置。正式版移除 DeepSeek/Gemini 夺舍续写的运行入口和供应商探测请求，停用旧续写开关。原指令入口保留，其中夺舍指令改为说明实验包位置。

带夺舍的 0.3.4 源码独立保存在 [experimental/possession](https://github.com/Akavilos/astrbot_plugin_spectrum_core/tree/experimental/possession)，可[下载实验包](https://github.com/Akavilos/astrbot_plugin_spectrum_core/archive/refs/heads/experimental/possession.zip)。它依赖框架内部请求方法，仅供实验，不作为插件市场正式发行版。正式版与实验版不要同时安装。

## 日志、升级与验证

生产源码统一使用 `astrbot.api.logger`。旧版源码已备份；升级前仍应备份自己的插件配置及数据目录，替换插件源码并重载即可。

必要离线检查覆盖原生请求字段、临时背景、人物与来源、跨会话话题召回、睡眠、承诺取消、世界书触发、限频、冻结持久化及旧结果拒绝。这些检查不请求在线模型或发送 QQ 消息，也不代表所有模型的实际表达都能保证一致。插件市场是否接纳仍以重新审核结果为准。
