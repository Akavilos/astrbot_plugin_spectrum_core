# 光谱核心使用指南

适用版本：0.3.2。先完成 [README 中的安装步骤](../README.md)，设置的完整默认值见 [配置参考](配置参考.md)。

## 1. 先建立角色，再开启需要的能力

模型选择和基础人设在 AstrBot 中设置。光谱会把人设、共同生活、当前人物、记忆、世界书与近期往来组织成当前请求，并处理角色的生活更新和对外回复。

建议先开启光谱总开关，保留人物识别与私聊保护，进行普通聊天；需要自动行动时再开启承诺跟进、独立生活推进或导演。开启后台能力会产生额外模型请求。棱镜也会进行自己的理解与场景整理调用，应计入整体额度。

“整理后的对话历史”用于让光谱选择往来内容；“生活叙述风格”调整角色内部生活文字。后者默认使用第一人称，不等同于要求每条发出去的消息都写成日记。

## 2. 共同生活与跨会话交流

同一个角色有共同生活状态，各会话不各自生成一套独立处境。人物身份和记录受众用于决定当前会话可以读取什么；私聊内容是否能在群聊中使用由对应设置控制。

外出归属用来协调同行与位置，不代表其他会话被彻底隔离。承诺有各自对象、时间和状态；取消的计划不应继续作为有效安排使用。可在面板查看来源，或用 `/光谱核心 list` 检查当前会话的承诺和延迟消息。

当出现记错人、时间或计划的情况，先查人物档案、原始往来和生活线，再修正对应来源。只改一句现状不会自动修正所有历史认知。详细说明见 [人物关系与跨会话记忆](../RELATIONSHIP_UPDATE.md)。

## 3. 数据管理面板

从 AstrBot 插件管理中打开光谱的插件页面。面板与“插件配置”用途不同：配置控制功能开关，插件页面管理角色已经积累的数据。

| 页面 | 用途 |
|---|---|
| 任务计划 | 查看承诺，手动增加、改期、取消 |
| 消息队列 | 查看延迟消息，修正内容和时间，作废或恢复待发状态 |
| 认知管理 | 添加、修改、删除长期认知，查看可用来源与生活状态 |
| 叙事日志 | 查询、修改或删除往来记录 |
| 人物档案 | 查看人物关系及其认知，调整档案 |
| 生活线 | 查看生活片段、修改片段信息、解除外出归属 |
| 导演 | 管理剧情素材、故事线与故事状态，查看只读执行记录和模拟安排 |
| 工具 | 查看框架已注册的工具，补充或清除工具用法说明 |
| 世界书 | 新建、修改、启停和删除背景条目 |

恢复待发消息前先核对聊天记录，以免把已经送达的内容再发一次。删除一段生活可能连带删除段内记录；修改或删除原始记录，也不等于自动回滚已经整理出来的所有认知。

## 4. 指令速查

下列写法使用默认 `/` 前缀，实际唤醒方式以 AstrBot 配置为准。指令中的英文动作词直接照写即可。

### 查看与会话控制

| 指令 | 作用 |
|---|---|
| `/光谱核心` 或 `/光谱核心 status` | 查看总开关、当前会话、睡眠、生活归属与待发数量 |
| `/光谱核心 on` | 恢复当前会话的光谱接管，清除该会话格式失败计数 |
| `/光谱核心 off` | 停用当前会话接管，使用普通回复流程 |
| `/光谱核心 list` | 查看当前会话的承诺与延迟消息 |
| `/光谱核心 cancel <数字ID>` | 尝试取消该ID的承诺和延迟消息；以返回结果为准 |
| `/光谱核心 sessions` | 列出已知会话地址 |

`on/off` 控制当前会话，不修改配置中的全局总开关。`cancel` 会同时尝试两类记录；需要只操作其中一类时使用面板。

### 生活与睡眠

| 指令 | 作用 |
|---|---|
| `/光谱核心 where` | 查看共同现状、生活归属和行程 |
| `/光谱核心 out` | 将外出归属设为当前会话 |
| `/光谱核心 out <会话地址>` | 指定外出归属，例如从 `sessions` 复制完整地址 |
| `/光谱核心 back` | 解除外出归属，返回角色自己的生活线 |
| `/光谱核心 set <现状文字>` | 直接改写共同现状 |
| `/光谱核心 sleep` | 睡眠功能开启时强制入睡 |
| `/光谱核心 sleep <分钟>` | 指定入睡时长；显式分钟数可触发手动睡眠 |
| `/光谱核心 wake` | 手动唤醒，开启新的居家生活片段，清空睡眠未读箱 |

睡眠对整个角色生效，睡着期间各会话均不进行正常回复。配置中的最短和最长时间用于自动睡眠安排；手动指定时长按指令处理。自动睡眠的选择由模型与睡眠机制共同决定，插件没有固定“只能晚上睡”的时间表。手动唤醒会清空未读箱，不应把它当作“自动补答所有未读”的按钮。

生活指令还保留中文别名：`where` 可写“位置”“主线”“life”；`out` 可写“外出”“出门”；`back` 可写“回来”“回家”“归位”；`set` 可写“现状”“sethome”；`sessions` 可写“会话”。

### 叙述外部事实

| 指令 | 作用 |
|---|---|
| `/叙述事实 <外部场景>` | 记录角色可以感知的外部事实，本轮不产生角色回复 |
| `/叙述查看` | 查看最近10条叙述记录及其受众 |
| `/叙述删除 最近` | 删除最近3条叙述来源记录 |
| `/叙述删除 历史` | 保留最近3条，其余叙述来源删除 |
| `/叙述删除 all` | 删除全部叙述来源记录，直接执行 |

适合输入：“窗外下起了雨，玻璃上有水珠。”这类指令提供环境，不用于指定角色应当如何思考、说话或行动，也不直接替角色改写位置与处境。入口由代码审核，不为此调用模型；代码规则不能完整判断所有自然语言含义。

成功或被拒绝都不会在聊天中回提示。请用 `/叙述查看` 确认，未写入时查看日志中的 `[spectrum·看见]` 记录。点名人物会影响受众判断；无法确定相关会话的记录可能拒绝写入。删除来源后，已经整理到其他认知或现状里的内容不会自动回滚。

这些管理指令当前没有额外的身份权限校验；通过 AstrBot 的会话与指令权限设置安排可使用的范围。

### 异常暂停与实验模式

| 指令 | 作用 |
|---|---|
| `/光谱核心 冻结状态` | 查看异常暂停状态 |
| `/光谱核心 冻结` | 手动冻结运行状态 |
| `/光谱核心 解冻` | 手动恢复运行 |
| `/光谱核心 冻结重置` | 重置冻结控制状态 |
| `/光谱核心 mode` | 查看当前会话模式选择 |
| `/光谱核心 prefill` | 请求当前会话使用思考续写模式 |
| `/光谱核心 default` | 请求当前会话使用默认合约模式 |

异常冻结用于在失败期间暂停生活与任务推进，恢复时保持状态衔接。它与正常睡眠、投递哨兵的不可送达状态分别管理。“触发暂停的累计失败次数”按累计失败计数，解冻或重置后清零。

实验性自述思考有三个开关：总开关、DeepSeek续写、Gemini续写。会话模式选择仍服从总开关、对应模型开关和接口能力；不支持续写的请求使用普通路径。DeepSeek续写需要兼容的 `/beta` 端点；Gemini的接口兼容处理依实际提供商能力生效。

`prefill` 保留别名“think”“夺舍”，`default` 保留“contract”“合约”“默认”。这里的“思考”是角色输出中的自述文本，与模型原生推理不同，不能仅靠文本标签判断原生推理是否关闭。

## 5. 主动推进与剧情导演

承诺跟进负责已有约定，独立生活推进允许安静期间继续生活并按需要联系。群聊主动参与有单独开关和门槛。开启后仍要满足时间、意愿、睡眠、冻结和请求频率等条件，不表示每到检查时间就发送消息。

导演用于统一安排后台任务和剧情素材，并提供故事线、收尾与张弛节奏。导演开关、故事收尾、节奏和复杂条件模型判断分开控制。开始时保留高级项默认值，先观察面板中的执行记录；模型判断复杂条件与后台推进会增加调用。

## 6. 常见问题

**开启后没接管？** 检查总开关、使用范围、当前会话是否 `off` 或连续格式错误后暂时退避。修正模型或配置后可用 `on` 恢复会话。

**突然不回复？** 先查睡眠、冻结、哨兵状态与框架日志，再查待发队列。沉默有时来自角色决策，不一定是报错。

**没有主动联系？** 检查主动功能开关、安静时间、意愿门槛、模型是否可用，以及睡眠和冻结状态。后台检查间隔不是发消息周期。

**记忆没出现？** 检索只选择当前相关且可见的部分；先查记录是否已存、人物归属及私聊保护，再调整检索数量。原文回看默认关闭，需单独开启。

**设置保存后没变化？** 重载插件，检查修改的是当前分组。升级后的隐藏旧字段只用于兼容，不应手动改它们。

**插件页面打不开？** 确认宿主支持插件页面和 `register_web_api`，查看加载日志。配置页分组与数据面板是两个入口。
