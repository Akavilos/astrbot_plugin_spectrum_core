# 光谱核心 · Spectrum Core

光谱核心为 AstrBot 中的同一个 AI 角色管理共同生活状态、人物关系、跨会话记忆和行为安排。角色在不同私聊、群聊中交流时，可以延续同一段生活，并根据当前人物、可见信息和已有承诺组织回复。

**光谱与棱镜可以合作运行，构成由状态驱动的角色对话模式：光谱维护共同生活与行为状态，棱镜提供主观心情、人物感受和联想回忆。棱镜是可选组件，光谱可以单独运行。**

本版本：**0.3.4**。

## 主要功能

- 共同生活：记录当前处境、生活片段、行程与睡眠，在多会话中保持连续性。
- 人物与记忆：区分人物身份、私聊和群聊的信息范围，整理长期认知，并按话题检索记忆或回看原文。
- 行为安排：管理承诺、延迟消息、主动联系和群聊参与；相应功能可独立开关。
- 世界书：管理世界观、人物背景和知识条目，支持触发条件、篇幅预算与四种光谱原生注入位置。
- 剧情导演：管理剧情素材、故事线、介入节奏和后台任务。
- 运行控制：异常暂停、恢复、请求频率控制，以及实验性的角色自述思考与模型续写模式。
- 数据面板：查看和管理承诺、消息队列、认知、往来记录、人物、生活线、导演、工具与世界书。

## 安装与开始使用

1. 使用 AstrBot **4.24.0 或更新版本**，先确认机器人可以正常聊天，已配置模型与角色人设。
2. 将插件文件夹 `astrbot_plugin_spectrum_core` 放入 AstrBot 的 `data/plugins`，在插件管理中加载。文件夹内应直接包含 `main.py` 和 `metadata.yaml`。
3. 打开插件配置 → **开始使用**，打开“启用光谱核心”，选择使用范围。默认范围为私聊，总开关默认关闭。
4. 保存并重载插件，先用默认设置进行日常对话。发送 `/光谱核心` 查看当前会话状态。
5. 需要主观情绪与回忆时再安装棱镜，并在光谱配置中开启“使用棱镜的心情与回忆”。未安装棱镜时可以关闭此项。

第一次使用不需要修改工程文件。主动推进、承诺跟进、世界书、导演和异常暂停默认关闭，可在了解用途后逐项开启。睡眠和实验性自述思考有各自默认值，详见配置参考。

## 升级与数据

本版本会把旧版平铺设置迁移到对应分组，保留原有有效值。插件数据由 AstrBot 的插件数据目录保存；更换源码不需要删除聊天数据库。升级前备份插件文件、对应配置和插件数据目录，升级后保存并重载。

角色表达由模型、人设、记忆和状态共同影响。光谱提供连续生活与行为约束，实际回复质量还取决于所用模型对上下文和输出格式的理解。

## 全新安装与个人数据

发布源码不包含聊天数据库、人物资料、记忆、世界书条目、私人配置或部署凭据。全新数据目录中的聊天、人物、记忆、世界书和剧情素材均为空；由用户自行配置和积累。角色人设及专属称呼由 AstrBot 人设设置决定，插件只标明当前通信对象的身份。升级已有实例会保留原数据，不会执行清空。
